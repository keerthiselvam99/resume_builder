# Final visual review — changed preview baselines

This folder holds the evidence for the **28** views whose committed visual-regression
baselines (`frontend/e2e/visual-regression.spec.ts-snapshots/*.png`) no longer match the
current render. The product UI, templates, renderer and baselines were **not** changed in
this exercise — these screenshots exist so the changed previews can be reviewed and
approved before any baseline update is ever considered.

> Count note: the gate brief said "26 changed previews". The actual verified count is
> **28** — 25 template-preview (navy) views plus 3 approved-flow views
> (burgundy template preview, create resume, editor after template change). This was
> confirmed across four independent fresh-server full-suite runs (28/28 failures each).

## How the candidates were produced

1. Ran `e2e/visual-regression.spec.ts` in isolation against a fresh mock server
   (`--workers=1 --retries=0`).
2. Each of the 28 tests now fails with a genuine `toHaveScreenshot` pixel diff (0 timeouts).
3. The rendered `*-actual.png` files were copied here as `candidates/*.png`; the committed
   `-chromium-win32.png` snapshots were copied here as `baselines/*.png`; the pixel diff
   overlays as `diffs/*.png`.
